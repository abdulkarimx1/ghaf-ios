# Inspo notes (2026-11-18)

Source: `/Volumes/SSK SSD/My Files/Ghaf APP/Inspos/`. What the user wants, per folder.

## Shared palette (derived from the inspo, use everywhere)
- Canvas: soft off-white `#F3F3F1` (light), near-black `#0D0D0F` (dark).
- Surfaces: white cards with very soft shadow; frosted glass (blur + white 60%) on light, `#1A1A1C` on dark.
- Ink: `#0D0D0F`. Primary button = black pill, white text (every folder uses this).
- Accent: lime `#C8F560` (Wise green / premium card / widget highlights). Use for selected chips, positive values, Pro.
- Secondary accent: signal orange `#FF5A1F` (stats bars, live activities, alerts) - sparing.
- AI only: electric blue glow `#2F6BFF` → `#7FB2FF` (Siri-orb). No dark green, no sand.
- Big bold grotesk numbers, tight tracking. Centre-aligned headers and totals.

## Competitor notes (charts, budgets)
- Copilot Money: month bar = spent vs budget, colour by pace (green on pace, orange heading over, red over);
  outlined bars = expected recurring spend. Cash-flow card = stacked bars by category; tap a bar for key metrics.
  Users complain they must tap each month to see totals -> show the value tag on the selected bar always.
- Monarch: "Month in review" (top categories, cash flow, net worth change); month-over-month by category.
- YNAB: behaviour first; simple spending line + pie, budget envelopes with available amount.
- Revolut: spending chart toggles bar <-> pie (tap corner); sort by category/merchant/card; custom period.
  Users dislike trend hidden after redesign -> keep the trend line on top, always visible.
- Apple Stocks / Robinhood: one line, period chips under it, drag to scrub (value + date follow finger,
  haptic per point), line colour = up/down vs period start, morph between periods.
- Apple Card: weekly/monthly bars of spending coloured by category, tap bar -> list below filters.
- Takeaway for Ghaf: one hero trend (Stocks scrub), D/W/M/3M/Y chips, tappable bars that filter the list
  under them, pace colours for budget, category donut/petal with tap-to-focus. Values only from the ledger.
